# Vitrine Chogan — Next Face

Site vitrine (sans boutique) présentant les gammes Chogan : parfums, maison, soins, cheveux, maquillage, bien-être…

- `index.html` : la vitrine
- `equipe.html` : l'équipe Next Face
- `assets/js/produits.js` : **la liste des produits** — c'est ici qu'on ajoute/modifie un produit
- `assets/css/vitrine.css` : le style (noir & or)

## Mise en ligne sur GitHub Pages
Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)`.
Le site sera disponible sur `https://<utilisateur>.github.io/Nextface/`.
