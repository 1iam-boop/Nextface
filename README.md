# Vitrine Chogan

Site vitrine (sans boutique) présentant la gamme de soins Aurodhea by Chogan : brumes Lush Cloud, corps, visage, rasage, cheveux, solaire, remèdes, animaux.

- `index.html` : la vitrine
- `assets/js/produits.js` : **la liste des produits** (source : catalogue AW) ; mettre `AFFICHER_PRIX = false` pour masquer les prix
- `assets/css/vitrine.css` : le style (noir & or)

## Mise en ligne sur GitHub Pages
Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)`.
Le site sera disponible sur `https://<utilisateur>.github.io/Nextface/`.
